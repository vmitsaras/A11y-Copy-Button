From demo to your page

Two small steps.

Start with a native button and an adjacent status element. Then let the package enhance it.

npm install a11y-copy-button
index.html01 / Markup
<link rel="stylesheet" href="./dist/styles.css">
<button type="button" data-a11y-copy-button
  data-a11y-copy-button-value="https://example.com/accessible-media">
  <span data-a11y-copy-button-label>Copy link</span>
</button>
<span data-a11y-copy-button-status></span>
main.js02 / Enhance
import { createCopyButton } from "./dist/index.js";

const button = document.querySelector("[data-a11y-copy-button]");
if (button instanceof HTMLElement) {
  createCopyButton(button);
}

These relative paths match this published demo. In an installed app, import a11y-copy-button and a11y-copy-button/styles.css through your bundler. Clipboard writes generally need a secure context and user activation.

A small, practical API

What you can do.

Use the factory for a single control or initialize every marked button at once.

Full API reference
Exports and instance methods
APIWhat it does
createCopyButton(root, options?)Enhances one root and returns its instance. Calling it again for the same root returns that instance.
initCopyButtonAll(options?)Enhances all [data-a11y-copy-button] roots in the document and returns their instances.
new A11yCopyButton(root, options?)Constructs an instance directly; the factory function is the usual entry point.
instance.copy(value?)Attempts a copy. Pass a value to override the configured source for this attempt.
instance.setValue(value) / getValue()Updates or reads the configured copy value.
instance.setLabel(label) / setStatus(status, message?)Updates the button label or visible status feedback.
instance.disable() / enable()Changes the native button's disabled state.
instance.reset() / destroy() / init()Resets feedback, removes the enhancement, or reinitializes it.
instance.setLocale(locale, messages?) / t(key, params?)Changes messages or looks up a localized message.
instance.registerAddon(addon) / unregisterAddon(name)Adds or removes an addon hook object.
instance.getAddon(name) / getAddons()Reads registered addons.
COPY_BUTTON_EVENTSNames for lifecycle and copy result events emitted from the root.
addCopyButtonEventListener(target, name, listener, options?)Adds a typed event listener and returns an unsubscribe function.

Common options include value, sourceSelector, getValue, messages, resetDelay, and announceStatus. See the full API reference for every option, event, and addon hook.

✓

Built around the basics.

These examples use native buttons, so Tab, Enter, and Space work without custom key handling. Status appears beside the button and is announced politely by default. Focus remains on the button. The package CSS supports visible focus and reduced motion. Clipboard access can fail, so check the behavior in your target browsers and with assistive technology.
