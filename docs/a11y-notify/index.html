A11yCopyButton with A11y-Notify

Both buttons show visible feedback. A11y-Notify requests the accessible announcement, while focus stays on the button.

Automatic announcement transport

Uses document.ariaNotify() when available, or A11y-Notify’s live-region fallback.

Forced live-region announcement

Uses A11y-Notify’s live region even if document.ariaNotify() is available.

Copy failure

An empty value is rejected before any clipboard write. The visible error and announcement use the same message.

Last announcement transport: none yet.

The copy operation uses the Clipboard API when available. This example opts into the copy button’s deprecated clipboard fallback separately from the announcement transport.
